## Getting Started

### Prerequisites

- Node.js 18.17+
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then visit:

```text
http://localhost:3000
```

> If port 3000 is unavailable, Next.js will automatically switch to the next available port such as 3001.

---

## Production Build

```bash
npm run build
```

Serve the production build locally:

```bash
npm run start
```
